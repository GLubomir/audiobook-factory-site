Privacy Policy

Audiobook Factory. Last updated: October 2026.

Who this applies to

Audiobook Factory is a desktop program that runs on its owner's own computer and is used by that one person for the owner's own YouTube channel. This policy explains what the program does with the Google account data it can reach after the owner signs in.

What data the program accesses

With the owner's permission, through Google sign-in, the program can:

  • upload videos to the owner's YouTube channel (youtube.upload);
  • read and change the settings of the owner's channel and videos, such as titles, descriptions, thumbnails, subtitles and playlists (youtube.force-ssl);
  • read the statistics of the owner's channel, such as views, watch time and retention (yt-analytics.readonly).

The program also keeps the sign-in token that Google gives it, so that the owner does not have to sign in again for every action.

How the data is used

The data is used only to do what the owner asks inside the program: publish the owner's videos, keep their descriptions up to date and show the owner how the channel is doing, and to prepare recommendations for the owner (see "Sharing" below). It is not used for advertising, profiling, selling or any other purpose.

Where the data is stored

  • The data is kept on the owner's computer. The program has no server of its own and does not upload your data anywhere, except for the one exception described under "Sharing".
  • The sign-in token is stored on the computer in encrypted form, protected by Windows (DPAPI), so it can be read only by the owner's Windows user account.
  • Channel statistics are saved in a local database on the same computer.
  • Backup copies of the program's data, including that database, are made on the owner's own disks.

Sharing

The data is not sold, and it is not given to advertisers or to the author of the program. There is one exception, and it is stated here plainly: to prepare recommendations for the owner, the program gives the summary numbers of the channel and the titles of the owner's own videos (views, watch time, audience retention, traffic sources and click-through rate from the exported reports) to the Claude AI assistant made by Anthropic. It runs through the owner's own subscription on the owner's computer. Nobody else receives this information. Passwords, sign-in tokens and the contents of the owner's account are never given to the assistant. Apart from this, the program talks to Google to carry out the owner's actions on the owner's channel. The use of information received from Google APIs adheres to the Google API Services User Data Policy, including its Limited Use requirements.

How to remove the access

The owner can stop the program's access at any time, in either of these ways:

  1. In the program, open the channel page and choose to disconnect the channel. The sign-in token is deleted from the computer.
  2. In the Google account, open myaccount.google.com/permissions, choose Audiobook Factory and select "Delete all connections" (or "Remove access"). Google then stops accepting the token.

To remove the data that is already on the computer, delete the program's data folder and its backup copies on the owner's disks. The program keeps nothing on any server of its own.

Changes to this policy

If the program starts to use data in a different way, this page will be updated before that change is used.
